# Repository workflow

- Commit completed changes regularly in coherent groups, especially before more
  than 50 outstanding files accumulate. Run the checks relevant to each change.
- Keep progress reports focused on completed work, findings, and material limits.
  Once the owner has established a constraint, follow it without repeatedly
  announcing what is being omitted.
- The owner packages beta maps. Work on sources and editable assets unless a
  build or packaging step is explicitly requested.
